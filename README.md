# hcmus-student-handbook-chatbot
# 🎓 Student Handbook Chatbot (HCMUS)

## Overview
This project builds a chatbot to answer student questions based on the HCMUS student handbook.  
The chatbot uses Gemini 2.5 API to generate responses from provided data.

---

## Objectives
- Answer student-related questions  
- Use handbook data as knowledge source  
- Provide fast and accurate responses  

---

## Tech Stack
- Python  
- Gemini 2.5 API  
- (Optional) LangChain / RAG  
- (Optional) Streamlit / Web UI  

---

## Dataset
The data is collected from the HCMUS student handbook.  
Content is processed and used as the knowledge base for the chatbot.
